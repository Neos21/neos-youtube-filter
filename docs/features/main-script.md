# メインスクリプトの起動と操作

`npm run build` または `npm run build:ytf` で生成する `/ytf.js` は、eval・Tampermonkey の @require で評価された時点で自動起動する。

## 起動とトークン

起動時は、対象サイト・重複起動の確認、トークン読込、キャッシュ読込、操作メニュー配置、カード処理・監視開始の順に処理する。キャッシュがない場合だけ、メニュー配置前に API から取得する。

トークンは YouTube 側の LocalStorage の `ytf:token` に保存する。未保存・空欄の場合は、起動時に一度だけ prompt で入力を求める。キャンセル・空入力なら終了し、再評価しても入力を求め直さない。再入力する場合はページを再読み込みする。

`window.__YTF__` は重複起動を防ぐ印だけに使用する。状態の取得や外部からの操作用メソッドは公開しない。

API URL は [constants.ts](../../scripts/constants.ts) の `apiBaseUrl`。公開コードや URL にトークンを埋め込まない。通信では固定 Bearer トークンを使用する。

401 が返った場合は保存トークンを削除し、監視を停止して本スクリプトが隠したカードを復元する。非表示と再取得の操作を無効にし、メニューに再読み込みの案内を出す。自動再入力・自動再試行は行わない。

キャッシュ利用中はトークンの確認 API も呼ばないため、有効性を確認するのは次の API 呼び出し時となる。`www.youtube.com` と `m.youtube.com` では LocalStorage の保存領域が異なる。保存できなくても、そのページでは入力したトークンと取得した条件を使用する。

## 呼び出し例

- [ブックマークレット](../../scripts/bookmarklet-example.js) : 登録時は先頭に `javascript:` を付ける。改行を除去する場合は先に行コメントも除去する
- [Tampermonkey](../../scripts/tampermonkey-example.js) : @require で本体を読み込むだけで起動する

配信先を変更する場合は、各例のスクリプト URL と本体の API URL を変更する。Trusted Types ポリシーの再作成や本体の重複起動が問題になる場合は、ページを再読み込みする。

## キャッシュと再取得

有効なキャッシュがあれば、起動時もページ移動時も API を呼ばない。キャッシュがない・破損・旧形式の場合の初回取得と、操作メニューの「再取得」でのみ `GET /api/filter-rules` を呼ぶ。定期ポーリングは行わない。

LocalStorage の `ytf:filter-rules` に次の判定用情報だけを保存する。

- `blocked_videos` : 動画 ID の配列
- `blocked_channels`・`subscribed_channels` : `handle`・`channel_id` の配列
- `blocked_patterns` : `type`・`pattern`・`flags` の配列

DB の `id`・`created_at`・参考用 `title`、取得日時・版・API URL は保存しない。以前の全レコードを含むキャッシュは初回取得で置き換える。

通信失敗・不正応答では現在の条件を保持し、ログとメニューにエラーを表示する。初回取得にも失敗した場合は動画を隠さず、利用者が「再取得」で試し直す。401 の場合は前述のとおり停止する。

## 非表示判定と操作メニュー

右上の `details` メニュー「YTF」を開くと、非表示 ON/OFF・再取得・ログ表示を操作できる。エラーがある場合は閉じた状態でも「YTF !」と表示する。

ホーム・動画ページへの移動時は非表示 ON、検索結果では OFF に戻す。同じページの追加描画やハッシュだけの変更では、手動で切り替えた状態を維持する。対象外ページでは非表示操作を無効にする。

動画 ID・チャンネル ID・ハンドルは個別カードの HTML に含まれるかを調べる。ID の大文字小文字は保持し、ハンドルは小文字化して URL エンコード表現も照合する。購読チャンネルも非表示の対象とする。

文字列パターンと正規表現はカードの textContent に対して評価する。タイトル・チャンネル名以外に、説明文や視聴回数も対象となる。文字列は大文字小文字を区別しない部分一致、正規表現は保存したフラグで評価する。不正な正規表現はログに通知して、その条件だけを除外する。自分で追加した UI の文字列は照合に含めない。

非表示には `.ytf-hidden` クラスを使用し、既存の style 属性は変更しない。OFF・条件変更・カードの再利用・対象外ページへの移動で、不要になった非表示を解除する。動画ページは関連動画欄だけを対象とし、Shorts 専用プレイヤーは対象外とする。

セレクタ候補は [youtube-selectors.ts](../../scripts/dom/youtube-selectors.ts) にまとめる。初回・ページ移動・条件変更・トグル変更では全体を再判定し、通常の DOM 変更では追加・変更されたカードだけをまとめて処理する。詳細な動画情報の取得や登録ボタンは後続タスクで実装する。

## デバッグログ

起動、キャッシュの読込・保存、API 開始・終了・HTTP ステータスと失敗理由、ページ判定、処理カード数、非表示・復元の対象と一致理由、監視停止を console.log・console.error に出力する。トークン・Authorization ヘッダー・送信本文・カードの HTML 全体はログに出さない。

メニューの「ログ」を ON にすると、コンソールと同じ内容を読み取り専用テキストエリアに表示する。選択・コピーでき、スマホでも開発者ツールなしで確認できる。ON/OFF は `ytf:debug` に保存する。

履歴は直近200件・1件2000文字まで。メニューが閉じている間とログ OFF 中はテキストエリアを書き換えず、表示時に保持していた履歴を反映する。コンソール出力と履歴の保持は継続する。YouTube や他の拡張機能のコンソール出力は捕捉しない。

機能が揃ってから開発者がデプロイ・実機確認を行う。実機の YouTube、Safari、Tampermonkey の検証は、模擬 DOM・API によるブラウザ検証とは区別する。
